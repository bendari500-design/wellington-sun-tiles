# wellington-sun-tiles

Static data for the Wellington region sunlight map: <https://bendari500-design.github.io/my-website/sun/all/>

This branch (`gh-pages`) is generated by `/workspace/wellington-sun/region/publish_region.sh` and is **replaced by a single new
commit on every rebuild** (force-push), so the repository history does not grow.

| path | content |
|---|---|
| `meta.json` | layers, palette (64 levels), maximum per layer, extent, zoom range, counts |
| `tiles/<layer>/<z>/<x>/<y>.webp` | XYZ (Web Mercator) sun-hours tiles, layers `total`, `am`, `pm`, `jun`, `dec`, zoom 11-16 (2 m source); transparent outside the 150 m address mask, on the sea and where there is no LiDAR |
| `addr/index.json`, `addr/14/<x>/<y>.json` | per-address garden/roof scores in chunks by z14 tile; rows follow `cols` (new columns can be appended) |
| `search.json` | address search index grouped by street (label list + chunk keys) |
| `suburbs.json` | simplified LINZ suburb/locality outlines and label points |

Data: LINZ LiDAR DSM/DEM, NZ Addresses, NZ Building Outlines, NZ Suburbs and Localities (CC BY 4.0).
